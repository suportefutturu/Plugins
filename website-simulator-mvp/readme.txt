== Description ==

**Website Simulator MVP** is a powerful WordPress plugin that allows agencies and freelancers to create interactive website simulators for their clients. Capture leads, provide instant estimates, and showcase your services professionally.

### Features

*   **Multi-Step Questionnaire**: Intelligent forms with progress tracking
*   **Visual Site Preview**: Show clients how their future website will look
*   **Dynamic Price Calculation**: Real-time estimates based on user selections
*   **Lead Capture**: Store simulation data and contact information
*   **Admin Dashboard**: View statistics and manage simulations
*   **Customizable Questions**: Edit questions and options from the admin panel
*   **Flexible Pricing Rules**: Configure pricing for different project types
*   **Responsive Design**: Works perfectly on all devices
*   **Email Notifications**: Automatic emails to admin and clients
*   **GDPR Compliant**: Consent management built-in

### Shortcode

Use `[website_simulator]` to display the simulator on any page or post.

### How It Works

1.  Client answers questions about their project needs
2.  Plugin calculates estimated price and timeline
3.  Visual preview shows what the website could look like
4.  Contact information is captured
5.  Simulation is saved to database
6.  Admin receives notification email

### Admin Features

*   **Dashboard**: View key metrics and recent simulations
*   **Simulations List**: Filter, search, and manage all submissions
*   **Questions Manager**: Create and edit questionnaire items
*   **Pricing Rules**: Configure values for different options
*   **Settings**: Customize branding, colors, and behavior

== Installation ==

1.  Upload the `website-simulator-mvp` folder to `/wp-content/plugins/`
2.  Activate the plugin through the 'Plugins' menu in WordPress
3.  Go to Website Simulator > Settings to configure the plugin
4.  Add the shortcode `[website_simulator]` to any page
5.  Start collecting leads!

== Frequently Asked Questions ==

= Can I customize the questions? =

Yes! Go to Website Simulator > Questions to edit, add, or remove questions.

= How do I change the prices? =

Navigate to Website Simulator > Pricing Rules to configure values for each option.

= Where are the simulations stored? =

All simulations are stored in your WordPress database in custom tables prefixed with `wsmvp_`.

= Can I export the data? =

Yes! Go to Simulations and click "Export CSV" to download all data.

= Is the plugin GDPR compliant? =

The plugin includes consent checkboxes and doesn't store unnecessary personal data. Make sure to configure your privacy policy text in Settings.
